Votre personnage

1. La planche

Choisissez ou glissez ici votre sprite sheet (PNG de préférence). Elle reste sur cet appareil : rien n'est envoyé.

2. Les poses

Choisissez l'animation, puis cliquez sur ses poses dans la planche, dans l'ordre. Les cadres bleus sont les poses détectées.

0 pose

Cliquez sur la planche pour placer la première frame de l'animation choisie.

3. En jeu

La croix cyan marque le point posé au sol. En détection automatique, il est calculé pour chaque pose ; les champs Pieds ne servent qu'à la grille.
